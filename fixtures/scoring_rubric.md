# Shared evidence scoring rubric

Evaluate only proposal content. 0: no supported information. 1-3: vague/weak. 4-6: partial but plausible detail. 7-8: strong specific detail. 9-10: exceptionally complete, measurable commitments supported by text. Use each active criterion description as the assessment rubric. A named certification is an unverified supplier assertion, not independently established compliance. Pricing is assessed for clarity, comparability and assumptions, not simply the lowest number. Quote exact supporting text; explain absent information. Do not preassign winners.
